# USBCANFD

CAN FD(CAN with Flexible Data-rate)는 기존 CAN 버스를 확장한 최신 규격으로, 한 프레임에 최대 64바이트의 데이터를 실을 수 있으며 데이터 구간(Data Phase)에서 최대 5Mbps(일부 장비는 실험실 환경에서 최대 8Mbps)의 전송 속도를 지원합니다.
USBCANFD 시리즈는 고성능 CAN FD 인터페이스 카드입니다. 1 8채널의 CAN FD 인터페이스를 제공하며, ISO CAN FD와 Bosch(non-ISO) CAN FD 규격을 모두 지원합니다. 채널마다 2500VDC 절연 내압의 독립 절연 보호 회로를 갖춰, 접지 루프(ground loop)로 인한 카드 손상을 방지하고 가혹한 환경에서도 시스템 신뢰성을 높여 줍니다.
PC는 USB 2.0 포트를 통해 USBCANFD 카드에 연결하여 CAN(FD) 네트워크의 데이터를 송수신할 수 있으며, 이로써 PC가 하나의 CAN(FD) 버스 제어 노드로 동작합니다. USBCANFD는 Windows와 Linux 운영체제를 지원하고, ZXDoc과 ZCANPRO 소프트웨어를 기본으로 제공합니다. 또한 사용자가 직접 애플리케이션을 개발할 때 호출할 수 있는 2차 개발용 함수 라이브러리(API)도 제공하므로, CAN(FD) 버스 제품 개발과 데이터 분석에 유용한 도구로 활용할 수 있습니다.
